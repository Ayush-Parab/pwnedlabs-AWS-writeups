# PwnedLabs AWS Writeups ☁️🔐

Welcome to my repository of writeups for [PwnedLabs](https://pwnedlabs.io/) AWS cloud security challenges! 

## 📖 About
This repository contains my personal notes, walkthroughs, and solutions for various AWS-focused security labs. I created this repo to document my cloud security learning journey, track my progress, and share my methodology. 

I highly recommend attempting the labs on your own before reading the solutions here!
